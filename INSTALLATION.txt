G.I.B. CONNECT V0.9.4 — Outils en mode Modérateur uniquement

Depuis V0.9.1, V0.9.2 ou V0.9.3 : aucune modification Firebase nécessaire.
Décompresser le ZIP puis déposer son contenu dans le dépôt GitHub existant avec Add file > Upload files > Commit changes. Attendre le déploiement terminé et actualiser avec Ctrl+F5.
Ne supprimer ni le dépôt ni les données.
Depuis une version antérieure à V0.9.1 : publier d’abord REGLES_FIREBASE.txt dans Firebase > Firestore Database > Règles.

Dans Profil > Mode d’utilisation, choisir Modérateur pour afficher les outils de création. Cette option apparaît uniquement pour les comptes autorisés.
En mode Membre : aucun formulaire de création d’événement, terrain, sondage ou annonce ; aucun bouton de nouvelle conversation ni d’invitation. Les outils de gestion des profils, cotisations, grades et accès sont également masqués.
Les conversations déjà disponibles restent utilisables : on peut lire, envoyer et supprimer ses propres messages, répondre aux événements et voter aux sondages.
Le passage en mode Membre ferme les formulaires ouverts. Aucun passage automatique en mode Modérateur.
Le compte principal conserve la gestion exclusive des quatre places de modérateurs, accessible en mode Modérateur.
Le logo, le menu Membre et les insignes des grades sont conservés.
