G.I.B. CONNECT V0.9.7 — NOTIFICATIONS A CONFIGURER

1. Lire serveur-google/CONFIGURATION.txt et créer le service Apps Script.
2. Publier REGLES_FIREBASE.txt dans Firebase > Firestore Database > Règles.
3. Décompresser le ZIP et remplacer les fichiers de l’application dans le dépôt GitHub existant. Conserver index.html à la racine. Le dossier serveur-google sert à préparer le serveur, il peut rester sur l’ordinateur.
4. Après le déploiement, fermer et rouvrir l’application. Sur ordinateur, Ctrl+F5.
5. Compte principal > Profil > Mode Modérateur > Service de notifications : URL /exec et activation.
6. Chaque téléphone : Profil > Activer les notifications sur cet appareil.
7. Faire le test réel entre deux comptes décrit dans CONFIGURATION.txt.

Ne supprimer aucun compte ni aucune donnée Firebase. Ne jamais publier le JSON privé du compte de service sur GitHub ou dans le chat.
Les fonctionnalités et droits de V0.9.6 sont conservés. Les nouvelles règles sont nécessaires, même si V0.9.6 fonctionne déjà.
