G.I.B. CONNECT V0.9.10 — GPS AU FORMAT GOOGLE MAPS

Depuis V0.9.7 ou supérieure configurée : déposer tous les fichiers applicatifs de cette version dans le dépôt GitHub existant, y compris le nouveau gps.js. Attendre le déploiement puis fermer et rouvrir l’application. Sur ordinateur : Ctrl+F5.
Aucune modification Firebase ou Apps Script nécessaire. Ne supprimer aucun compte ni aucune donnée.

MODE MODERATEUR > TERRAINS
Le champ Coordonnées GPS — Google Maps accepte une paire complète :
48°50'41.2"N 0°58'21.3"W
Les cartes des terrains affichent désormais ce format. N/S indiquent le nord/sud ; E/W l’est/ouest. La lettre O (ouest) et les symboles typographiques de minutes/secondes sont également acceptés à la saisie.
Les degrés décimaux restent acceptés, par exemple : 48.844778, -0.972583.
Laisser le champ vide permet de conserver un terrain sans GPS.
Les valeurs existantes restent utilisables. Modifier seulement l’adresse ou les consignes d’un terrain conserve la précision de ses coordonnées d’origine.
L’affichage arrondit les secondes au dixième, comme dans l’exemple fourni. Le bouton Itinéraire / carte utilise les coordonnées numériques enregistrées.
L’exemple n’est attribué automatiquement à aucun terrain : le responsable doit renseigner les coordonnées réelles de chacun.
