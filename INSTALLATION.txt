G.I.B. CONNECT V0.9.5 — INSTALLATION SUR TELEPHONE

MISE A JOUR GITHUB
Décompresser le ZIP. Dans le dépôt GitHub existant : Add file > Upload files. Déposer tout le contenu au même niveau que index.html, y compris install.js, sw.js, manifest.webmanifest et les trois fichiers app-icon. Valider avec Commit changes.
Attendre le déploiement GitHub Pages, puis actualiser avec Ctrl+F5.
Depuis V0.9.1 ou supérieure, aucune modification Firebase nécessaire. Depuis une version plus ancienne, publier d’abord REGLES_FIREBASE.txt dans Firestore > Règles. Ne supprimer ni données ni utilisateurs.

INSTALLER SUR ANDROID / GALAXY TAB
Ouvrir https://gibairsoftvire.github.io/G.I.B-CONNECT/ dans Chrome.
Cliquer sur Installer l’application (page de connexion ou Profil), puis confirmer.
Si le navigateur ne propose pas la fenêtre : menu trois points > Installer l’application ou Ajouter à l’écran d’accueil. Ne pas ouvrir le lien dans le navigateur intégré de Messenger.

IPHONE / IPAD
Ouvrir le lien dans Safari. Partager > Sur l’écran d’accueil > Ajouter. Si proposé, activer Ouvrir comme app web.

ORDINATEUR
Ouvrir le lien dans Chrome ou Edge et utiliser le bouton Installer ou l’icône d’installation dans la barre d’adresse.

L’icône G.I.B. lance l’application dans sa propre fenêtre sur les navigateurs compatibles. L’installation est gratuite et ne passe pas par le Play Store ou l’App Store.
La première ouverture peut nécessiter une nouvelle connexion. Dans l’application installée, la connexion est conservée sur cet appareil jusqu’à déconnexion ou révocation des droits. Se déconnecter sur un appareil partagé.
Internet reste nécessaire pour Firebase et les données partagées. Les notifications à distance, application fermée, ne sont pas encore activées. L’installation seule ne les active pas.
Les règles et fonctionnalités de V0.9.4, le logo original, les insignes et le mode Modérateur sont conservés.
